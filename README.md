# Atlantic Route Atlas

crea un atlas geographico che mostra il mondo intero. mi interessa principalmente la tratta da lisbona ad halifax in canada. dovro visualizzar ei cambi di rotta dovuti alla presenza di eventi meteomarini come l'altezza d'onda. voglio un visual dove posso poi aggiungere altri grafici e businness side
